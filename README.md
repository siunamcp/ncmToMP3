# NCM 解密转 MP3 工具

一个开箱即用的 **Windows 桌面应用**：把网易云音乐加密下载的 `.ncm` 文件，一键解密并转成 **任何播放器都能直接播放的 MP3**。支持批量处理、码率自由选择、自定义输出目录。

---

## 一、软件位置

- **可执行程序**：`dist\NcmToMp3.exe`（单文件，约 38 MB，双击即可运行，无需安装）
- **源码**：`app.py`（图形界面）、`decrypt_core.py`（解密与转码核心逻辑）
- **说明文档**：`README.md`（本文件）

> 提示：`dist\NcmToMp3.exe` 是完整的独立程序，**内置**了解密和转码引擎，拷到其他 Windows 电脑也能直接运行，不依赖本机安装任何 Python 或工具。

---

## 二、这个软件基于什么制作

| 组件 | 用途 | 说明 |
|------|------|------|
| **Python 3.11** | 开发语言 | 负责界面与业务流程控制 |
| **Tkinter** | 图形界面框架 | Python 自带的标准 GUI 库，无需额外依赖 |
| **ncmdump 1.5.1**（开源） | 解密引擎 | 用于无损解开 `.ncm` 加密壳，还原原始音频 |
| **FFmpeg 6.0**（开源） | 转码引擎 | 负责码率控制（128/192/320kbps）与非 MP3 源转码 |
| **PyInstaller 6.22.3** | 打包工具 | 将以上所有内容打包成单个可执行 `.exe` |

三者均以**嵌入二进制**的方式打包进 `NcmToMp3.exe`，因此软件本身不依赖外部环境，开箱即用。

## 三、核心功能

1. **批量解密** —— 可一次添加多个 `.ncm` 文件，或直接添加一个包含 ncm 的整个文件夹，逐首自动处理。
2. **码率自由选择** —— 下拉框可选：**原码率（无损）、128 kbps、192 kbps、320 kbps**。
   - 选「原码率」：若源就是 MP3，直接无损保留；若非 MP3 源则转为 320kbps MP3。
   - 选指定码率：自动把歌曲转为该码率（如果当前已是该码率则直接保留，不重复压缩）。
3. **自定义输出目录** —— 解密后的 MP3 保存位置可自由指定，并支持一键「打开输出目录」。
4. **实时进度与日志** —— 处理过程在后台线程执行，界面不卡顿；日志区实时显示每首歌的状态与结果。
5. **手动停止** —— 处理途中可随时点「停止」，当前文件处理完后即止。
6. **工具自检** —— 启动时自动检查内置引擎是否就绪，异常会明确提示。

## 四、使用说明

1. **启动程序**：双击 `NcmToMp3.exe`，等待窗口打开（首次启动因内置引擎解压需稍等几秒）。
2. **添加歌曲**：点「添加文件」选择一个或多个 ncm；或点「添加文件夹」把整个目录里的 ncm 全部加入。列表会显示待处理文件，可「移除选中」或「清空列表」。
3. **设置输出目录**：在「输出目录」输入框填写保存位置，或点「浏览」选择文件夹（默认是程序所在目录下的 `mp3` 文件夹）。
4. **选择码率**：在「码率」下拉框选择期望的输出质量。
5. **开始解密**：点「开始解密」，下方日志会显示处理进度。处理完成后弹出提示，并可点「打开输出目录」查看结果。
6. 处理完成的 MP3 文件名与原歌一致（如 `Hayd - Head In The Clouds.mp3`），可直接用任意播放器播放。

## 五、解密原理简述（为什么是无损）

`.ncm` 是网易云音乐的**加密容器**，内部其实存放的是一条完整的 MP3 / FLAC 音频流，只是被 AES 加密包裹了一层壳。

- **还原密钥**：从文件头还原出被混淆的 **AES-128 密钥**。
- **解开音频**：用该密钥以 **AES-128-ECB** 模式逐块解密，得到纯音频字节流。
- **输出 / 转码**：将音频流写为 MP3；再按所选码率用 FFmpeg 处理。

因此**选「原码率」时是逐比特无损还原**，音质与网易云服务器上的原始文件完全一致，比"播放再录音"的方式更好（无二次压缩损耗）。

## 七、注意事项

- **合法使用**：请仅解密你自己账号合法下载的 `.ncm` 文件，请遵守网易云音乐相关服务条款。
- **首次启动较慢**：单文件程序启动时需要把内置引擎解压到临时目录，属正常现象。
- **系统要求**：Windows 10 / 11 64 位，无需预装任何运行环境。
- **源文件保护**：程序只读取和解密你选中的 ncm，不会修改或删除源文件。

## 八、常见问题

**Q：提示"工具缺失 / 无法正常工作"？**
程序内置引擎未正确加载。请确认直接双击的是 `dist\NcmToMp3.exe`，而不是源码文件；必要时重新拷贝一份该 exe 再运行。

**Q：某首歌解密失败？**
多为该 ncm 文件已损坏或非标准加密格式，日志区会显示具体原因，可单独尝试重新下载该歌曲。

**Q：输出文件比原文件小/大？**
属正常：选了更低码率会变小；原文件本身含元数据，体积会有少量差异。以能正常播放为准。
